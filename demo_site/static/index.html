TekmerDB Demo

TekmerDB is a domain-scoped engine — it has to be told upfront which EU AI Act risk category it's operating in. Every claim is checked against a similarity gate for that domain, and claims that drift outside it get rejected; this keeps confidence scoring meaningful and specific to the regulatory context, instead of one fuzzy pool of unrelated facts. Pick a domain below to launch an instance scoped to it.

Sources

A source is whoever submitted a claim (a PDF upload, pasted text, or a manual insert) — each gets tracked with an effective weight that rises with corroboration and falls when it triggers a conflict.
